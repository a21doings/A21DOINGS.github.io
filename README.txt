PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub as A21doings.
2. Open https://github.com/new
3. Repository name: A21doings.github.io
4. Choose Public, then Create repository.
5. On the repository page choose Add file > Upload files.
6. Upload index.html, style.css and script.js (not this ZIP).
7. Select Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select Branch: main and folder: /(root), then Save.
11. Wait a few minutes, then visit https://a21doings.github.io
